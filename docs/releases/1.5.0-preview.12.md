# 1.5.0-preview.12

2026-10-26

本次更新重点改善设置可靠性和冷启动播放，提供 Android APK 与 Windows／Android 完整源码。

## Android

- 主题、语言、音量、倍速、循环方式等设置统一持久保存，连续修改不再相互覆盖；保存失败会保留上一次已保存的值。
- 启动时先恢复原生主题和语言，再显示主界面，避免旧网页缓存覆盖简体、繁体、英语或法语选择。
- 改善应用未打开时的媒体会话连接，保留耳机、通知和系统媒体控制触发的首次播放操作。
- 修复保存设置期间启动播放后，界面已显示新音量／倍速而实际播放器仍使用旧值的问题。
- 改善歌曲与歌词小组件的冷启动、超时处理和刷新，避免过期回调重复执行控制操作。
- 关闭界面时及时结束等待中的界面调用；已接受的设置保存继续完成，后台播放保持独立。
- 关闭并重新开启播放进度恢复时，旧恢复点不会重新出现；队列、收藏、歌单和历史继续保留。
- APK 附带项目和第三方开源许可文本。

原有 WebDAV、离线下载、歌词三级查询、封面模糊背景、本地推荐、多 API 歌单、睡眠定时和可选交叉淡化继续提供。预取与自动资源检索仍默认关闭。

## Windows 源码

- 升级 Electron、媒体元数据解析和构建依赖。
- 加固 SQLite 迁移、事务回滚和新版本数据库保护，避免不兼容版本写坏数据。
- 设置以已提交的数据库内容为准，修复快速修改、失败重试与旧缓存之间的覆盖问题。

## 下载与升级

- Android：`Aurora-Music-Android-1.5.0-preview.12-debug.apk`，Android 7.0 及以上。
- 源码：`Aurora-Music-Next-1.5.0-preview.12-Source.zip`，同时包含 Windows 和 Android 入口。
- 校验：下载后可使用 `SHA256SUMS.txt` 核对文件完整性。

Android versionCode 为 18，沿用 preview.11 的应用标识和签名，可尝试直接覆盖安装。不要先卸载；如系统提示签名不一致，请保留应用与数据并反馈。GitHub Actions 临时生成的 debug 包可能使用不同签名。

## 已知限制

- 本版本为预览版。部分 M4A、特定 WebDAV 服务端、HyperOS 后台限制、蓝牙耳机与长时间息屏仍需设备验证。
- 完整数据导出／跨端恢复与正式签名迁移尚未提供。
- Windows 安装包暂不随本次发布：所含 FFmpeg 的完整对应源码和构建材料尚待补齐；源码和本地构建功能保留。

## English

Preview 12 improves durable settings, native-first language/theme startup, cold media-session connections and widget controls. It fixes settings saved while a player starts, ends pending UI calls on teardown without cancelling accepted writes, and prevents obsolete playback checkpoints from returning. Windows source receives dependency and database-safety updates.

Install the Android APK over preview.11 without uninstalling first. This release uses the previous preview signing identity and versionCode 18. The source archive includes both platforms. Windows installers are deferred until the exact FFmpeg corresponding-source and build materials are available. This is a preview; device-specific playback, long-running background behavior and full backup/restore remain under development.
