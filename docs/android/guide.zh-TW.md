## Android Studio 編譯

準備 Node.js 22、JDK 21、Android SDK Platform／Build Tools 36。在同時含有 `package.json`、`mobile/`、`src/`、`android/` 的專案根目錄執行：

```sh
npm ci
npm run android:sync
```

Android Studio **Open → 選取 android 資料夾**，Gradle JDK 選 21，安裝 SDK 36 並等待同步。其終端執行：

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Windows 改用 `.\gradlew.bat`。APK 在 `android/app/build/outputs/apk/debug/app-debug.apk`。修改手機／共用 TypeScript 後，必須先在根目錄重新執行 `npm run android:sync`。

也能上傳解壓後的原始碼，保留 `.github/`，在 **Actions → Android debug APK** 執行工作流程，下載並解壓 `aurora-android-debug`。只上傳一個 ZIP 不會編譯；不要上傳金鑰、私人資料庫、SDK/JDK 或快取。

## 使用與火車離線聆聽

1. 設定填 HTTPS WebDAV 音樂目錄、帳號與密碼，連線後到「雲端」掃描。不接受自簽憑證。播放及離線下載支援最多五次 HTTPS 轉址；離開原 WebDAV 目錄後，只允許公網目標並永久移除授權／Cookie，不將 WebDAV 帳密傳給 CDN。拒絕 HTTP 降級、內網目標及循環轉址。目錄及資源 API 限制不變。
2. 曲庫可瀏覽歌曲、專輯、藝術家與收藏，搜尋涵蓋整個曲庫；可建立普通／智慧規則歌單。音訊技術資訊只在二級詳細資料中。
3. 出發前用 Wi-Fi 下載，切「僅離線」並關網試播。只有完整下載可離線；串流快取不等於完整檔案。
4. 設定 →「下載工作」可查看進度、暫停／繼續／重試／取消並清理，每頁 60 首。暫停保留暫存檔；取消只清理本機未完成檔案，保留完整離線檔案及雲端音樂。相同強 ETag 與正確位元組範圍才能續傳，否則安全重下。關閉介面或切背景即停止進度輪詢。Wi-Fi 設定影響新工作。重試由系統排程，並非立即或永久執行保證；連續五次無淨進展錯誤即停止自動重試，可手動重試。極慢大檔仍須實機驗證。
5. HyperOS 允許背景執行、取消電池限制，可按需鎖定最近工作。原生播放服務不能保證永遠不被終止，強制停止會結束播放。
6. 桌面長按 → 小工具 → Aurora，選歌曲或歌詞樣式，可調整大小。不支援直接加入時可手動新增；歌詞僅在亮屏換行時更新。

## 個人化與播放設定

<img src="../images/android/download-tasks.png" width="280" alt="下載工作頁，模擬進度與原生呼叫">

系統／明亮／深色、桌布動態色、自訂強調色、動畫及低耗電視覺可調整。低耗電模式不顯示大面積封面模糊背景。介面與小工具支援四種語言。

「封面氛圍背景」可獨立關閉，移除模糊圖層但保留清晰封面。不額外查詢圖片；低耗電視覺／系統省電仍優先停用背景。

歌詞字級可選 18／24／30／36，亦保留系統字體縮放。快速連續變更外觀會依序儲存。播放設定可關閉「還原上次歌曲與進度」：清除還原點，但不刪目前佇列、收藏、歌單或聆聽紀錄。重開後從目前播放儲存新還原點，不取回已清除的舊進度。

設定顯示串流快取及封面占用。「清理串流快取」移除未使用片段，保留讀取中的快取，可換歌後再清。固定 128 MiB 上限是磁碟快取，不是應用程式記憶體。已下載歌曲直接讀本機檔案，不重複快取；清理不刪離線音樂、封面及曲庫資料。快取不能替代出發前的完整下載。

<img src="../images/android/storage-settings.png" width="280" alt="離線儲存與串流快取分開管理，模擬資料">

點底部歌曲進入全螢幕播放器。點歌詞跳到該句，點「歌詞」回到目前行；「⋯ 更多操作」放詳情、資源查找及播放設定。返回逐層關閉，取消選單不改目前值。「封面氛圍背景」須開啟並關閉「低耗電視覺」；系統省電仍優先停用模糊與動畫，不額外查圖。

<img src="../images/android/phone-player.png" width="280" alt="全螢幕歌詞播放器，模擬歌曲與原生呼叫，並非實機截圖">

重新掃描可從 `周杰伦-星晴.m4a`、`Artist - Song.mp3` 等常見檔名推測資訊。只修復藝術家仍空白、歌名仍為原始檔名的條目，不覆寫標籤、手動改名、收藏、歌詞或離線檔案，也保護同時剛讀取的標籤。不猜測專輯；多連字號與英文無空格名稱保留原樣。這是檔名推測，並非已讀取的音訊標籤。

播放器開「⋯ 更多操作」→「播放設定」，或設定開「播放與聆聽裝置」。可選單曲／清單循環、完整歌單隨機、0.5–2× 倍速、程式音量與睡眠計時，再按儲存。原生計時到期暫停；處理程序結束後不恢復計時，重新開啟不會自動播放。

「標籤音量一致化（只衰減）」預設關閉。儲存後依既有 ReplayGain 曲目增益／峰值降低音量，不放大、不降噪、不重新編碼；無可用標籤不處理，應用程式音量仍是上限。支援 MP3 TXXX、FLAC/Vorbis 註解及 M4A iTunes 自由標籤，不再次套用專輯增益、R128、Opus 頭增益或 Sound Check。缺失、異常或超出安全範圍的數值忽略，不猜測 0 dB；曲目標籤只在二級歌曲詳情顯示，切歌重設係數，關閉即可恢復原音量。實機音量切換及實際檔案標籤提取尚待驗證。

同一對話框的「提前快取下一首」預設關閉，開啟後須儲存。等目前播放不再載入、穩定 5 秒後，以原生工作嘗試快取下一首完整檔案；僅已知大小且不超過 64 MiB 的線上歌曲，略過已下載及排隊／下載中的工作。共用 128 MiB 已提交串流片段，不另存離線副本；不呼叫 AI，也不標成「已離線」。快取可能被移除，出發前仍須完整下載。

「交叉淡化」提供關閉／1／2／3 秒，儲存後生效。接近曲尾或手動切歌才使用第二路原生播放器，準備最長 8 秒，未就緒則正常切換；單曲循環、直播、過短或時長未知的歌曲不自動重疊。暫停、拖動進度、關閉及系統省電會結束淡化；準備中暫停保留所選歌曲但不開播。兩路共用焦點及降低音量，線性係數總和不超過程式音量上限；實際混音仍須驗證。緩衝有界、不將整曲解碼進記憶體，但會短暫增加解碼器／耗電並可能使用行動數據，故預設關閉。

遵守下載的 Wi-Fi／非計量限制；關閉限制可能使用行動數據。暫停、切歌、目前播放重新載入／緩衝、系統省電、網路變化或關閉開關會取消請求。單次最長 90 秒，不連續重試失敗；清快取後目前歌曲期間不重新預取。寫入分片最多 2 MiB，未提交片段及索引另有磁碟開銷，128 MiB 不是記憶體上限。更新後鍵值加入來源大小／修改時間，舊串流片段可能需重取，仍依額度淘汰；完整離線檔案不變。實機快取復用及取消尚待驗證。

<img src="../images/android/playback-options.png" width="280" alt="二級播放與裝置設定，演示資料">

裝置清單只代表系統可見輸出，不代表目前路徑、藍牙編碼或實際取樣率；請用系統媒體面板切換。來源檔案資訊不是錄音品質保證，預設不加增益／降噪。

## 找得到歌曲，但播放失敗？

覆蓋安裝本版，不要解除安裝、清空資料或刪除曲庫。先試 MP3，再試 M4A。點底部歌曲開啟播放器，檢視繁體說明與 `AUDIO_…` / Media3 錯誤碼；失敗後按一次「播放」重試，失敗狀態不持續背景輪詢。

- `AUDIO_HTTP_401` / `403`：下載被拒絕；能列目錄不代表有下載權限，請檢查帳號及 WebDAV 下載服務後重新連線。
- `AUDIO_NETWORK` / `TIMEOUT` / `TLS`：網路、逾時或憑證問題；不會略過憑證驗證。
- `AUDIO_REDIRECT_…` / `NOT_AUDIO` / `RANGE`：轉址、伺服器回傳網頁／錯誤資訊或位元組範圍問題。
- `AUDIO_FORMAT` / `DECODER`：檔案容器／裝置解碼問題，不同於網路失敗。

回報錯誤碼、檔案格式及裝置／系統版本即可。Logcat 可篩選 `AuroraPlayback`；不要分享帳密、簽名連結或原始伺服器回應。本地測試不使用你的伺服器，仍須實機複測播放、拖動進度、離線下載及斷網播放。

## API、歌詞與隱私

本地推薦不用 API。設定填服務網址、准确模型 ID 與 Key，再調整優先順序。支援 Chat Completions、Responses、Anthropic、Gemini；請選提供方實際支援的協定，不自動猜模型。

自然語言歌單預設本地生成。選用 AI 才傳提示、偏好摘要及有界候選元資料，不傳音訊、WebDAV 網址、原始歷史或憑據。回退可能向多家服務發送／計費；關閉生成頁或切背景可取消未完成請求，不能撤銷既有費用。

歌詞按「歌名＋藝術家＋專輯 → 歌名＋藝術家 → 歌名」三級查找，每級依優先順序嘗試啟用的歌詞 API，再用 LRCLIB。設定 →「歌詞、封面與背景來源」最多 10 個服務，可設獨立加密 Bearer 金鑰、類型與順序。這是 JSON 資源介面，不是聊天模型網址。儲存不傳測試請求，已存金鑰不回傳介面；換網址須重填。

封面優先內嵌、自有或已設定來源。iTunes 預設關閉、須另行確認；開啟不代表取得圖片授權，請先閱讀 [Apple 條款](https://performance-partners.apple.com/search-api)。背景預設放大並模糊封面、不額外連網；設定背景 API 後可手選獨立背景。

歌曲詳細資料 →「搜尋預覽與手動選擇」可改搜尋資訊，最多 8 筆結果；點選才下載圖片預覽，確認後才替換對應資源，不更動其他資源、音訊、歌單與紀錄。手選封面不被音訊標籤覆蓋。關閉或進入背景即取消並清理暫存預覽；憑證 10 分鐘後失效，須重新搜尋。還原僅清理對應本機手選圖片，不更動雲端。

<img src="../images/android/asset-settings.png" width="280" alt="資源介面優先順序及預設關閉的 iTunes，模擬設定">

GET 參數為 `title`、`artist`、`album`、`kind`；回傳 `results` 陣列，歌詞欄位 `lyrics`、圖片欄位 `imageUrl`。僅公開 HTTPS，拒絕內網、重新導向與介面查詢參數；圖片僅同來源時可帶金鑰，跨來源 CDN 不帶。JSON 2 MiB、圖片 8 MiB 上限；保存最長邊 ≤768px JPEG，不重新編碼音訊。自動封面快取合計 64 MiB／400 張；手選另限 64 MiB／400 張、不自動移除，滿時須替換或還原。詳見 [介面說明](../API_INTEGRATION.md)。

查找須同意傳送中繼資料，服務可能收費。Responses `store: false` 不保證中轉方不留資料。Keystore 加密金鑰，不加密所有音訊及曲庫。詳見 [隱私邊界](../../PRIVACY.md)。

## 覆蓋更新與限制

新增 **Android signed APK** 手動 CI 與拒絕不合簽章的建置／APK 校驗。正式金鑰及固定公開指紋由你自行設定，未替你生成或上傳；實際 CI 與覆蓋保留資料仍須驗證。請看[四語言簽章指南](release-signing.md#繁體中文)。新 release 金鑰通常不能覆蓋舊 debug，勿先卸載。

相同應用 ID、相同簽名憑證及合適 versionCode 可覆蓋安裝。正式版須長期保存同一私密簽名。不同電腦／CI 的 debug 簽名可能不同；簽名衝突時不要自動卸載或清資料，先找原簽名重編。資料匯出尚未齊全，卸載可能丟失歌單、憑據與離線音樂。

ReplayGain 只衰減、選用下一首預快取及原生交叉淡化已接入，仍待實機驗收。固定簽章建置已接入，正式金鑰設定、實際 CI／覆蓋安裝、資料交換仍須完成；本機圖片／側車歌詞匯入另列後續工作流程。Android 使用 Media3／系統解碼，不含 Windows FFmpeg；M4A/ISOM/MP42 不足以保證 AAC/ALAC 能播。

編譯、原生單元測試與模擬介面／API 測試通過，原生整合測試目前僅完成編譯。息屏續播、編碼、小工具、記憶體／耗電／發熱與系統大字體仍須兩台實機驗收。參閱 [完整清單](../ANDROID_REQUIREMENTS.md) 與 [安全發布門檻](../../SECURITY.md)。
